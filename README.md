### 使用说明

- **复制链接**：每个链接都放在代码块里，鼠标移到代码块右上角会出现复制按钮，点一下即复制。
- **一键导入**：在已装好对应 App 的设备上点击徽章按钮，会通过 URL Scheme 直接拉起 Shadowrocket / Clash 并添加配置。
- **镜像链接**：当 `raw.githubusercontent.com` 无法访问时，改用 jsDelivr 镜像（注意镜像有缓存，更新可能延迟几分钟到几小时）。
- 配置内仍需自行填入你的节点订阅，规则与策略组已预置。
